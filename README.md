# 📝 MyTodosList

A simple Todo List application built using **React** with basic routing (Home & About pages).

This project demonstrates React fundamentals such as:
- Components
- useState Hook
- Props
- Event Handling
- React Router Navigation

---

## 🚀 Features

- ➕ Add new todos
- ❌ Delete todos
- 📋 View all tasks
- 🏠 Home page
- ℹ️ About page
- 🔄 Real-time UI updates

---

## 🛠️ Built With

- React
- React Router DOM
- JavaScript (ES6+)
- HTML5
- CSS3

---

## 🏠 Pages

### Home
- Displays Todo list
- Add new Todo
- Delete Todo

### About
- Displays information about the application
